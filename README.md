# Nexo Joven 🚀
> Plataforma digital de participación juvenil, prácticas formativas y voluntariado territorial.

**Prototipo de solución estratégica en el marco del ENJU · Grupo Pampa Activa**
*Sede Piloto: General Pico, La Pampa*

---

## 🌟 Acerca del Proyecto

**Nexo Joven** surge como respuesta a la falta de canales accesibles para que las juventudes (16 a 18+ años, estudiantes secundarios y de escuelas técnicas) encuentren oportunidades de participación vinculadas con sus intereses y con las necesidades de su comunidad.

### Características Principales:
- 📍 **Foco Territorial**: Iniciando en General Pico, La Pampa con arquitectura escalable para la Región Pampeana.
- 🗺️ **Mapa Territorial Interactivo**: Exploración de actividades sobre el mapa urbano de General Pico con georreferenciación y filtros por barrio.
- 🎓 **Acreditación de Horas**:
  - `Acredita Horas Escuela Técnica`: Prácticas formativas y profesionalizantes técnicas/industriales (EPET).
  - `Acredita Horas`: Prácticas formativas generales.
  - `Voluntariado`: Participación comunitaria libre y lúdica.
- ⭐ **Aval Oficial**: Distintivo para actividades con respaldo de ministerios o municipios.
- 📋 **Mis Actividades & Circuito de Seguimiento**:
  - Inscripción (✓) ➔ Confirmación (✓) ➔ Participación (En curso) ➔ Acreditación (Certificado Digital).
- 👤 **Perfil Personalizado**: Recomendaciones dinámicas (*Para vos ✨*) basadas en intereses y orientación técnica.
- 🏢 **Conexión Multiactoral**: Modal para que escuelas, clubes, municipios, ONGs y cooperativas publiquen oportunidades.

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Brunoarci/Nexo-J-ven.git
   cd Nexo-J-ven
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abrí [http://localhost:3000](http://localhost:3000) o el puerto indicado en tu terminal.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

## 🌐 Despliegue en GitHub Pages / Vercel / Netlify

### Opción A: Vercel / Netlify
1. Conectá tu repositorio `https://github.com/Brunoarci/Nexo-J-ven` en [Vercel](https://vercel.com) o [Netlify](https://netlify.com).
2. Detectará automáticamente **Vite**.
3. El comando de build es `npm run build` y el directorio de salida es `dist`.
